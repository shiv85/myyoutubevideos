# Ancient India History Bot — Shiv Maurya Vlogs

Every morning (~6 AM India time) this bot, running free on GitHub, makes and uploads:

| | Long video | Short |
|---|---|---|
| Length | 10–12 minutes, 1920×1080 | 45–58 seconds, 1080×1920 |
| Voice | Hindi male narrator (`hi-IN-MadhurNeural`) | same |
| Inside | Title card, 8 chapters with headings, slow-zoom pictures, Hindi subtitles, original background music | Hook + subtitles + same music |
| Extras | Thumbnail, Hindi title/description/tags, YouTube chapter timestamps, image credits | `#Shorts` title, link to the long video |
| Upload | **Private** — you check it and press Publish | **Private** |

Topics come from `topics.txt` (68 ready topics, from Mohenjo-daro to Konark, including Prayagraj/Kaushambi
history). When the list ends, the bot invents new topics and never repeats one (`state/history.json`).

## How copyright is avoided

| Part | Source | Why it's safe |
|---|---|---|
| Script | Written fresh by AI for each video, instructed never to copy | Original text |
| Voice | Generated by Microsoft Edge text-to-speech | No one else's recording |
| Pictures | Wikimedia Commons **only** if licence = Public Domain, CC0, CC BY, CC BY-SA. Optional Pexels (free licence). Otherwise a generated art card | Free licences; every CC BY / BY-SA image is credited in the description automatically. Film posters, actors, logos, "fair use" files are rejected |
| Music | Synthesised by the bot itself (tanpura-style drone) | Original, so no Content ID claims |
| Fonts | Hind (SIL Open Font Licence, file `fonts/OFL.txt`) | Free for video use |

Want to be extra strict? Set `"image_licenses": "public_domain_only"` in `config.json`.

## One-time setup (about 40 minutes)

### 1. Put the code on GitHub
1. Create a free account at github.com → **New repository** → name `history-bot` → **Private** → Create.
2. **Add file → Upload files** → drag in everything from this folder → Commit.
3. Check the file `.github/workflows/daily.yml` is there. (Some computers hide folders starting with a dot.
   If it's missing: **Add file → Create new file**, type `.github/workflows/daily.yml` as the name, paste its contents.)

### 2. Get a script-writing key (pick ONE)
- **Free:** Google Gemini → https://aistudio.google.com/apikey → Create API key.
  Save as GitHub secret `GEMINI_API_KEY`.
- **Best Hindi quality:** Claude → https://console.anthropic.com → API Keys (pay-as-you-go, a few rupees per video).
  Save as GitHub secret `ANTHROPIC_API_KEY`.

To add a secret: repo → **Settings → Secrets and variables → Actions → New repository secret**.

### 3. Connect your YouTube channel
1. Go to https://console.cloud.google.com → create a project named `history-bot`.
2. **APIs & Services → Library** → search **YouTube Data API v3** → **Enable**.
3. **OAuth consent screen** → External → app name `history-bot`, your email → Save.
   Add your Gmail under **Test users**.
   Then press **Publish app** (status "In production"). ⚠️ If you skip this, the login expires every 7 days.
   You'll see an "unverified app" warning when logging in — that's normal for your own personal app; click
   **Advanced → Go to history-bot**.
4. **Credentials → Create credentials → OAuth client ID → Desktop app** → Create → **Download JSON**.
   Rename it `client_secret.json`.
5. On your computer (needs Python): put `client_secret.json` next to `get_youtube_token.py`, then run
   ```
   pip install google-auth-oauthlib
   python get_youtube_token.py
   ```
   Log in with the Google account that owns **Shiv Maurya Vlogs** (pick the channel if asked) → Allow.
6. Add the 3 printed values as GitHub secrets: `YT_CLIENT_ID`, `YT_CLIENT_SECRET`, `YT_REFRESH_TOKEN`.
   **Never upload `client_secret.json` to GitHub or share these values.**
7. Verify your channel with your phone at https://www.youtube.com/verify (needed for custom thumbnails).

### 4. (Optional) More photos
Free key from https://www.pexels.com/api → secret `PEXELS_API_KEY`.

### 5. First test
Repo → **Actions** tab → enable workflows → **Daily ancient-India video → Run workflow** →
untick "Upload to YouTube" → Run. After ~30–45 min open the run → **Artifacts** → download and watch.
Happy? Run it again with upload ticked. From now on it runs every day by itself.

## Your 5-minute daily routine
1. YouTube Studio → **Content** → today's 2 **Private** videos.
2. Watch quickly; spot-check names and dates (AI can make mistakes — this is why uploads are private).
3. Set **Visibility → Public** or **Schedule** (e.g. 6 PM for long, 12 PM for the Short).

Don't skip this review: YouTube does not pay ads on "mass-produced / repetitive" content, and a wrong fact
in a history video costs trust. Recording your own 10-second intro now and then, or replying to comments,
makes the channel clearly yours.

## Settings (`config.json`)
| Key | Meaning |
|---|---|
| `voice` | `hi-IN-MadhurNeural` (male). Try `en-IN-PrabhatNeural` for English |
| `voice_rate`, `voice_pitch` | e.g. `"-5%"` slower, `"-6Hz"` deeper |
| `target_minutes_min/max` | long video length (default 10–12) |
| `make_long`, `make_short` | turn either off |
| `privacy` | `private` (default), `unlisted`, `public` |
| `music_volume` | 0.05 quieter … 0.15 louder |
| `synthetic_media_disclosure` | tells YouTube the voice is AI (keep `true`) |

Change the time: edit the `cron` line in `.github/workflows/daily.yml` (time is UTC; India = UTC + 5:30).
Make a specific video now: **Run workflow** and type a topic.

## Costs & limits
- GitHub Actions: private repos get 2,000 free minutes/month; this uses roughly 1,000–1,400. A public repo has no limit
  (but keep secrets as secrets — they stay hidden either way).
- YouTube API: 10,000 units/day free; 2 uploads + thumbnail ≈ 3,300.
- Gemini free tier or Claude pay-as-you-go for scripts; voice, pictures, music are free.

## If something fails
Open **Actions → the red run → Make (and upload) today's videos** and read the last lines.
- `No LLM key found` → add `GEMINI_API_KEY` or `ANTHROPIC_API_KEY`.
- `invalid_grant` → YouTube login expired: publish the OAuth app (step 3.3) and run `get_youtube_token.py` again.
- `quotaExceeded` → wait until tomorrow.
- `thumbnail not set` → verify the channel (step 3.7).
- Video files from failed uploads are still in **Artifacts** for 2 days.

Test locally without internet: `python -m bot.main --offline` (silent audio, sample script).
